# жэбик

*для любимой кыци (=^・ω・^=)*

Мила гра про жабку на латтях: стрибай по клітинках, лови мух язиком, з'їж
**рівно N** мух — і стрибай на лотос-вихід. Уся графіка й музика згенеровані
кодом (pygame-ce + numpy), шрифт — M PLUS Rounded 1c (OFL).

Зараз готова **Збірка 1** (профілі, меню UA / EN / RU, налаштування, «Як грати»,
рівень 1-1 зі змією, пауза, перемога/поразка, музика й звуки) і **каркас світів**:
заставка студії «21th MANGO CAT», усі 12 рівнів у виборі (ще не зроблені — «скоро»),
заглушки рівнів 2-1 (Земля) і 3-1 (Небо), режим TOBI PIZDA, рекорди, сюжетні
заставки й титри. Повне ТЗ — у [`docs/TZ.md`](docs/TZ.md), як влаштований код і
як додавати світи — у [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Запуск

Потрібен Python 3.11 (підійде 3.10+).

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python3 frog.py
```

> Не ставте одночасно `pygame` і `pygame-ce` — вони конфліктують.
> Якщо старий `pygame` уже є: `pip uninstall pygame`, потім `pip install -r requirements.txt`.

### Windows 11 через WSL (WSLg)

У Windows 11 WSLg сам показує вікно гри й грає звук — нічого додатково
налаштовувати не треба.

```bash
sudo apt update && sudo apt install -y python3 python3-venv python3-pip
cd ~/frog                           # краще тримати проєкт у домашній теці Linux, не в /mnt/c
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python3 frog.py
```

Якщо вікно не з'являється або немає звуку — оновіть WSL у PowerShell:
`wsl --update`, потім `wsl --shutdown` і відкрийте термінал знову.

### Або звичайний Python для Windows

Встановіть Python 3.11 з python.org (галочка «Add to PATH»), потім у PowerShell:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
py frog.py
```

## Керування

| Дія | Клавіші |
|---|---|
| Стрибок на 1 клітинку | стрілки або WASD (утримання — стрибати далі) |
| Суперстрибок через клітинку | Shift + напрям (перезарядка 3 с, кільце на панелі) |
| Язик (2 клітинки в напрямку погляду) | Пробіл |
| Язик в інший бік, не стрибаючи | Пробіл + стрілка |
| Пауза | Esc або P (або клік по «Esc — пауза») |
| Повний екран | F11 (або в налаштуваннях) |
| Меню | стрілки / Enter / Esc або миша |
| Сенсорний екран | свайп — стрибок, тап по полю — язик, кнопка ⇧ (праворуч унизу) — наступний свайп буде суперстрибком, ⏸ (ліворуч унизу) — пауза. «Сенсорне керування» в налаштуваннях: Авто / Увімк / Вимк |

## Правила (EZZZ)

- 3 серця. Падіння у воду або укус змії — мінус серце і 2 с невразливості.
- Муха +1, бабка +2. Лічильник показує `k / N` — треба **рівно** N.
  Зайва муха — мінус серце («Обжерлась!»).
- Золота муха — +1 серце (максимум 3), світлячок — 5 с язик на 4 клітинки.
  Вони в лічильник не рахуються.
- Коли з'їдено рівно N — «Сита!» і десь далеко з'являється лотос. Застрибни на нього.
- Зірки: ★ — пройшла, ★★ — без ударів, ★★★ — без ударів і швидше за контрольний час.

## TOBI PIZDA

Відкривається після проходження всіх рівнів на EZZZ. Сердець немає: будь-який удар,
падіння чи зайва муха — рівень починається заново. Замість сердець — таймер (свій
для кожного рівня), золота муха дає +10 с. Прогрес, зірки й рекорди — окремі.

Заставку студії можна пропустити будь-якою клавішею чи тапом. Свою музику для неї
можна покласти в `jebik/assets/audio/intro_custom.ogg` (або `.wav`).

## Збереження

Профілі, прогрес і налаштування зберігаються у `~/.jebik/save.json`
(теку можна змінити змінною оточення `JEBIK_SAVE_DIR`). Пошкоджений файл
відкладається як `save.json.corrupt`, гра стартує з чистого.

## Для розробки

```bash
pip install -r requirements-dev.txt
python3 -m pytest                         # тести (headless)
python3 tools/screenshot.py screenshots   # PNG усіх екранів (headless), --lang en|ru, --only earth
python3 tools/gen_audio.py                # перегенерувати музику й звуки
JEBIK_AUTOQUIT=3 python3 frog.py          # запустити і вийти через 3 с
JEBIK_NO_SPLASH=1 python3 frog.py         # без заставки студії
```

Структура:

- `jebik/game/` — чиста логіка без pygame (поле й пастки, жабка, мухи, базові класи ворогів і босів, правила) — її покривають тести;
- `jebik/worlds/<water|earth|sky>/` — світи: вороги, графіка, рівні `levels/*.txt`, тексти, налаштування;
- `jebik/art/` — спільна процедурна графіка (жабка, мухи, заставка студії), рендер із суперсемплінгом і кешем;
- `jebik/scenes/` — екрани (заставка, меню, гра, HUD, рекорди, сюжет), `jebik/ui/` — кнопки, повзунки, фокус;
- `jebik/progression.py`, `records.py`, `story.py` — відкриття рівнів, таблиці рекордів, сюжетні заставки;
- `jebik/config.py` — спільні числа, `jebik/i18n.py` — спільні тексти.
